# Changelog

## 1.0.1

- Исправлен запрос PIN: в приложении кнопка «Выслать PIN» шлёт
  `pin_type=device` (не `login`) — теперь интеграция делает так же.
- Запрос PIN и вход разделены на два шага (как в приложении): новый PIN
  больше не перезаписывается попыткой входа в том же запросе.
- Ответ сервера на запрос PIN проверяется: превышение лимита
  («не более 3 ПИН в сутки»), ошибки доставки и другие сообщения
  показываются пользователю, а не маскируются под «Неверный PIN».
- Все ошибки входа/PIN сопровождаются текстом от сервера.
- Версия протокола не менялась; обновление обязательно при первом входе
  с нового устройства.

## 1.0.0

- Первый релиз.
- Кнопка «Открыть» для каждого КПУ.
- Шлагбаум как `cover` с предполагаемым состоянием (открывается → открыто → закрыто).
- Живая камера КПУ: MPEG1-TS из WebSocket-прокси, декодирование через ffmpeg.
- Сервис `amvideo.open_barrier` для автоматизаций.
- Вход по телефону и паролю, поддержка PIN-кода устройства (SMS).
- Автоповтор входа при истечении сессии (reauth-flow).
- Кулдаун открытия (20 с, настраивается), keep-alive опрос сервера.
